# CodePilot AI

CodePilot AI is an enterprise AI-powered developer assistant designed to help engineering teams understand codebases, analyze production issues, review code, and search source code semantically.

## Core Capabilities

- Repository Import
- AI Codebase Chat
- Retrieval-Augmented Generation
- Semantic Code Search
- Exception Analysis
- Log Analysis
- AI Code Review
- API Documentation Generation
- SQL Query Optimization

## Technology Stack

- Spring AI

### AI Infrastructure

## Architecture

CodePilot AI follows a layered backend architecture with clear separation between API, business logic, persistence, security, and AI infrastructure.
